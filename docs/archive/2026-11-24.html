One GPU, seven models: SageMaker can now slice a GPU for inference
AWS added NVIDIA Multi-Instance GPU (MIG) to SageMaker real-time endpoints. One A100 or H100 is split into up to seven isolated slices, each with its own memory, and SageMaker handles placement and scaling.
up to 7
models per A100 / H100
P4d, P5, G7, G7e
supported instances
WHY IT MATTERS TO YOU
Small models (classifiers, embedders, rerankers) no longer need a full GPU each. Same hardware, fewer endpoints, lower bill.
TRY IT IN 5 MINUTES
In CreateEndpointConfig add AcceleratorPartitionLayouts (for example mig-1g.5gb), then set AcceleratorPartitionType on each inference component. Works only on inference-component endpoints, not serverless.
