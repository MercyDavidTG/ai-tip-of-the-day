Weekend fix: Docker Engine 29.9.3 closes five security holes
Released 3 Nov, with a Canadian Cyber Centre advisory on 4 Nov for Docker Desktop and Buildx. The fixes cover Swarm overlay networks losing encryption after a firewalld reload, a SwarmKit certificate escalation, and a BuildKit cache-poisoning crash.
4 CVEs
plus BuildKit 0.34.2 fixes
10 min
to check and update
WHY IT MATTERS TO YOU
Every model we containerise builds through BuildKit. A patched engine is the cheapest security win of the week.
TRY IT IN 5 MINUTES
Run docker version --format "{{.Server.Version}}". If it is below 29.9.3, update Docker Desktop (Settings, Software updates) or the engine package on servers.
Also new: Docker Hardened Images are free and Apache 2.0. Swap one base image in a side project and compare the CVE count.
