DeepSeek's API now does web search, OCR, speech and file reading
DeepSeek opened the tools from its own app to developers. On deepseek-flash you switch on web search or URL reading with a tool flag, and OCR, speech-to-text and text-to-speech are now separate APIs.
5
new built-in tools
3 APIs
OCR, ASR, TTS
WHY IT MATTERS TO YOU
A cheap OCR plus LLM route for invoices, delivery notes and scanned forms, without stitching three services together.
TRY IT IN 5 MINUTES
Add the deepseek_read_url tool to a Chat Completions call and ask it to summarise a public report link. Then try the OCR API on one scanned document (no company data).
